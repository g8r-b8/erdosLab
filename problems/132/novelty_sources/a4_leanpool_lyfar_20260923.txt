# Exceptional-Word Closures for the Convex Three-Distance Case of Erdős Problem 132

This project proves the convex three-distance degree-six theorem. A maximal-gap
choice and the five-row enumeration route all thirteen canonical words through
four shared geometric realization predicates. Full-two-rung, terminal,
anti-saturation, and four-edge kernels close every route, so the source-facing
reduction is unconditional. The development also records exceptional-branch
rigidity, an explicit majorant counterexample, and rational regression
witnesses. The general-k suggestion and Erdős problem 132 remain open.

=== lyfar/rare-distance-fields README.md
# Rare-distance bounds over specified coordinate fields

A Lean 4 formalization of a completed restricted result motivated by [Erdős problem 132](https://www.erdosproblems.com/132).

For a finite set of **n distinct planar points**, call an occurring positive Euclidean distance **rare** if at most n unordered pairs realize it. Let r count all such distances. This project proves

**n ≤ 2^r**

in each of two settings:

1. Both coordinates of every point belong to **Q(sqrt(2))**.
2. Both coordinates belong to the image of a real Q-algebra embedding of **FractionRing (MvPolynomial sigma Q)**: a purely transcendental field **Q(T)**, with T algebraically independent over Q.

The two settings are stated separately. The results imply two rare distances for n ≥ 3 and at least k rare distances whenever n ≥ 2^k. Multiplicity always counts the complete unordered class in the original point set.

The project also proves exact rational specialization of finite configurations over Q(T), preserving every equality and disequality of distances. It does not preserve numerical ordering of lengths.

## Scope

This does **not** solve unrestricted Erdős #132. It does not cover arbitrary algebraic extensions of Q(T), the compositum Q(sqrt(2))(T), or all real configurations with rational squared distances. No mathematical novelty claim is made. This source package contains the complete arithmetic-coordinate project; other branches of the original research are outside its scope.

Proof provenance: **AI**, developed with Codex under Egor Lyfar's direction. License: Apache-2.0.

## Proof structure

- A bichromatic maximal-distance bound supplies the geometric counting step.
- Dyadic and octagonal integer descent construct a binary partition with decreasing integer height; height is separate from Euclidean length.
- The binary counting theorem yields n ≤ 2^r. Clearing denominators transports it to Q(sqrt(2)).
- Finite polynomial specialization preserves the distance-equality pattern. Clearing rational-function denominators extends the rational result to Q(T).

The public entry point is `LeanPool.RareDistanceFields.bounds`. Explicit results and their precise hypotheses are in `OctagonalRational.lean`, `DistancePattern.lean`, and `PureTranscendental.lean`; `project.yml` lists their fully qualified names.

## Reproduction

This repository is a source snapshot with a Lean Pool integration patch. Compile it in the pinned Lean Pool checkout below; it is not a separate Lake package.

Requirements: Git, elan, and the Lean toolchain pinned by Lean Pool. The pinned base uses Lean and Mathlib v4.34.0-rc1. A first cache download requires disk space for Mathlib.

```sh
git clone https://github.com/lyfar/rare-distance-fields.git
git clone https://github.com/Vilin97/lean-pool.git lean-pool-verification
cd lean-pool-verification
git checkout c8ddda0a64f21cb019720cdda48c94354d4091e7
git apply ../rare-distance-fields/lean-pool.patch
lake exe cache get
lake build LeanPool.RareDistanceFields
lake exe runLinter LeanPool.RareDistanceFields
lake exe lint-style LeanPool.RareDistanceFields
lake exe mk_all --check
```

For the additional axiom, compiled-environment, metadata, and static quality checks, install Lean Pool's pinned Python environment as described in its CONTRIBUTING.md, then run from `lean-pool-verification`:

```sh
python/.venv/bin/python ../rare-distance-fields/verify_project.py static
python/.venv/bin/python ../rare-distance-fields/verify_project.py axioms
python/.venv/bin/python ../rare-distance-fields/verify_project.py environment
```

The script calls the pinned pool's checker functions unchanged. Static checks cover the repository; declaration and environment audits target this project and its imported pool dependencies. These are project-scoped local checks. Full-pool CI and admission review are separate.

`manifest.json` identifies every included Lean file by SHA-256 and records the validation scope. The patch adds precisely the same Lean files, their project registry entry, and generated imports.

## Dependencies and source roles

The formalization reuses Mathlib and the existing angular-order geometry in `LeanPool.Erdos132N14.HopfPannwitzGeometry` (and its `Basic` dependency), from the pinned Lean Pool base. The conditional n=14 theorem is not imported.

[Erdős #132](https://www.erdosproblems.com/132) is motivation. D. R. Woodall, *Distances realized by sets covering the plane*, JCTA 14 (1973), 187–200, [DOI](https://doi.org/10.1016/0097-3165(73)90020-4), and David A. Madore, *The Hadwiger–Nelson problem over certain fields* (2015), [arXiv:1509.07023](https://arxiv.org/abs/1509.07023), provide rational/quadratic-field coloring background. They are not cited as sources asserting the rare-distance bounds proved here.
