# A conditional convex three-distance theorem for Erdős Problem 132

[![CI](https://github.com/lyfar/erdos-132-convex-k3-lean/actions/workflows/ci.yml/badge.svg)](https://github.com/lyfar/erdos-132-convex-k3-lean/actions/workflows/ci.yml)

This repository is the standalone origin for the Lean Pool project
`LeanPool.Erdos132ConvexK3`. It contains the same Lean modules with a minimal
pinned Lake project around them.

The result is conditional. It does not prove the convex `k = 3` case without
an extra interface, and it does not solve the general Erdős problem.

## Exact theorem

The headline declaration is
`LeanPool.Erdos132ConvexK3.convex_k3_degree_six_of_reduction`.

Consider a finite, nonempty configuration of labelled points in strict convex
position in the Euclidean plane. Join two labels when their squared distance is
one of the three largest realized classes. Lean proves that this graph has a
vertex of degree at most six, assuming
`ConvexTopThreeDraftReductionComplete`.

That single interface supplies the maximal-gap and thirteen-word reduction
together with the route closures. Its remaining source-facing boundary is the
coordinated-majorant selection step used in the proof sketch of Theorem 2.7 of
Erdős, Lovász, and Vesztergombi. The paper does not state that selection step
as a theorem.

## Formalized content

The Lean sources contain:

- the top-three distance graph, strict convexity, and diameter-lens geometry;
- penultimate-coordinate identities and the three-range metric dichotomy;
- the cover process, majorant paths, terminal cages, anti-saturation, and the
  thirteen-word assembly;
- use-site rigidity for the exceptional `(1,2)`, `(2,1)`, and `(2,2)`
  branches; and
- exact rational witnesses, including a convex heptagon that refutes the
  stronger universal longer-cover claim.

The development also records nonnested-pair witnesses that rule out a general
exchange statement. The theorem remains conditional on the one interface
named above.

## Source

Paul Erdős, László Lovász, and Katalin Vesztergombi,
[*On the Graph of Large Distances*](https://doi.org/10.1007/BF02187746),
*Discrete & Computational Geometry* 4 (1989), 541–549.

[Erdős Problem 132](https://www.erdosproblems.com/132) records the broader
problem.

## Reproducible verification

The repository pins Lean, Mathlib, and the dependency graph. From the
repository root:

```bash
lake exe cache get
lake build --wfail LeanPool.Erdos132ConvexK3
lake build --wfail
lake env leanchecker
./scripts/audit.sh
```

The audit strips Lean comments before checking forbidden executable tokens,
enforces the Lean Pool source-size bound, rebuilds with warnings as errors,
checks all 288 public declarations with `#print axioms`, and runs Lean's
independent environment checker. The accepted axiom footprint is limited to
`propext`, `Classical.choice`, and `Quot.sound`.

CI repeats the build, source audit, axiom audit, and environment check on
Ubuntu.
