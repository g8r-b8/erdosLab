 Abstract. 
 Given a set X ⊆ ℝ 2 X\subseteq\mathbb{R}^{2} of n n points and a distance d > 0 d>0 , the multiplicity of d d is the
number of times the distance d d appears between points in X X . Let a 1 ​ ( X ) ≥ a 2 ​ ( X ) ≥ ⋯ ≥ a m ​ ( X ) a_{1}(X)\geq a_{2}(X)\geq\cdots\geq a_{m}(X) 
denote the multiplicities of the m m distances determined by X X and let
 a ⁡ ( X ) = ( a 1 ​ ( X ) , … , a m ​ ( X ) ) a(X)=\left(a_{1}(X),\dots,a_{m}(X)\right) . In this paper, we study several
questions from Erdős’s time regarding distance multiplicities. Among other results,
we show that:
 (1) 
 If X X is convex or “not too convex”, then there exists a distance other than the diameter
that has multiplicity at most n n .
 (2) 
 There exists a set X ⊆ ℝ 2 X\subseteq\mathbb{R}^{2} of n n points, such that many distances occur with high
multiplicity. In particular, at least n Ω ⁡ ( 1 / log ⁡ log ​ n ) n^{\Omega(1/\log\log{n})} distances
have superlinear multiplicity in n n .
 (3) 
 For any (not necessarily fixed) integer 1 ≤ k ≤ log ⁡ n 1\leq k\leq\log{n} ,
there exists X ⊆ ℝ 2 X\subseteq\mathbb{R}^{2} of n n points, such that the difference between
the k th k^{\text{th}} and ( k + 1 ) th (k+1)^{\text{th}} largest multiplicities is at least
 Ω ⁡ ( n ​ log ⁡ n k ) \Omega(\frac{n\log{n}}{k}) .
Moreover, the distances in X X with the largest k k multiplicities can be prescribed.
 (4) 
 For every n ∈ ℕ n\in\mathbb{N} , there exists X ⊆ ℝ 2 X\subseteq\mathbb{R}^{2} of n n points, not all
collinear or cocircular, such that a ⁡ ( X ) = ( n − 1 , n − 2 , … , 1 ) a(X)=(n-1,n-2,\ldots,1) . There also
exists Y ⊆ ℝ 2 Y\subseteq\mathbb{R}^{2} of n n points with pairwise distinct distance
multiplicities and a ⁡ ( Y ) ≠ ( n − 1 , n − 2 , … , 1 ) a(Y)\neq(n-1,n-2,\ldots,1) .
 Keywords : distance multiplicity, convex layer decomposition, integer grid.
 1. Introduction 
 Let dist ⁡ ( x , y ) {\rm dist}(x,y) denote the Euclidean distance between points x x and y y in the plane.
Given a finite planar point set X = { x 1 , … , x n } X=\{x_{1},\ldots,x_{n}\} , let d 1 , … , d m d_{1},\ldots,d_{m} denote
the distinct distances between points in X X , where m = m ⁡ ( X ) ≤ ( n 2 ) m=m(X)\leq{n\choose 2} .
The multiplicity of d k d_{k} in X X is defined as
 a k ( X ) = | { ( i , j ) : 1 ≤ i < j ≤ n , dist ( x i , x j ) = d k } | . a_{k}(X)=\lvert\{(i,j)\colon 1\leq i<j\leq n,\,{\rm dist}(x_{i},x_{j})=d_{k}\}\rvert. 
 We arrange the m m multiplicities as a 1 ​ ( X ) ≥ a 2 ​ ( X ) ≥ ⋯ ≥ a m ​ ( X ) a_{1}(X)\geq a_{2}(X)\geq\cdots\geq a_{m}(X) ,
irrespective to relative values of the d k d_{k} ,
and let a ⁡ ( X ) = ( a 1 ​ ( X ) , … , a m ​ ( X ) ) a(X)=\left(a_{1}(X),\dots,a_{m}(X)\right) . In this paper, we revisit
several questions from the time of Erdős regarding distance multiplicities:
 (1) 
 Is it possible that all distances except the diameter have multiplicity
larger than n n ? See  [ 6 ] and  [ 9 , Conjecture 4] .
 (2) 
 Can it happen that there are many distances of multiplicity at least c ​ n cn ,
where c > 1 c>1 is a constant, or even superlinear in n n ? See  [ 10 ] and  [ 8 , Problem 11] .
 (3) 
 Estimate max X ⊆ ℝ 2 , | X | = n ⁡ ( a 1 ​ ( X ) − a 2 ​ ( X ) ) \max_{X\subseteq\mathbb{R}^{2},\,|X|=n}(a_{1}(X)-a_{2}(X)) , and more generally,
 max X ⊆ ℝ 2 , | X | = n ⁡ ( a k ​ ( X ) − a k + 1 ​ ( X ) ) \max_{X\subseteq\mathbb{R}^{2},\,|X|=n}(a_{k}(X)-a_{k+1}(X)) 
 as well as possible.
See  [ 5 , Section 3] .
 (4) 
 For sufficiently large n ∈ ℕ n\in\mathbb{N} , is it true that
 a ⁡ ( X ) = ( n − 1 , n − 2 , … , 1 ) a(X)=(n-1,n-2,\dots,1) if and only if X X consists of equidistant points on
a line or on a circle? See  [ 6 , p. 135] .
 We answer Questions ( 2 ) and ( 4 ), and give partial answers to the other two.
 1.1. Another distance with multiplicity at most n n besides the diameter 
 The diameter of X X , denoted Δ = Δ ⁡ ( X ) \Delta=\Delta(X) , is the maximum distance
between points in X X . Further, denote by Δ 2 = Δ 2 ​ ( X ) \Delta_{2}=\Delta_{2}(X) and δ = δ ⁡ ( X ) \delta=\delta(X) 
the second largest and the smallest distances in X X , respectively,
and by μ ⁡ ( X , d ) \mu(X,d) the multiplicity of the distance d d in X X .
 Hopf and Pannwitz  [ 16 ] proved that the
multiplicity of the diameter among any n n points in the plane is at
most n n . Erdős  [ 6 ] further conjectured that for any
 n n -element point set X ⊆ ℝ 2 X\subseteq\mathbb{R}^{2} , there must be a second
distance besides the diameter that has multiplicity at most n n .
 Conjecture 1.1 (Erdős  [ 6 ] , see also  [ 9 , Conjecture 4] ) . 
 Let n ≥ 5 n\geq 5 . For any X ⊆ ℝ 2 X\subseteq\mathbb{R}^{2} with | X | = n |X|=n , it is not
possible that every distance except the diameter occurs more than n n times. 
 The condition n ≥ 5 n\geq 5 is necessary, since for n = 4 n=4 we can glue two equilateral triangles
of the same side length together as a rhombus and this gives a counterexample. Erdős and
Fishburn  [ 9 ] proved the Conjecture for n = 5 , 6 n=5,6 and the case of n ≥ 7 n\geq 7 is still open.
Here we confirm Conjecture  1.1 in two special cases.
A point set X ⊆ ℝ 2 X\subseteq\mathbb{R}^{2} is said to be convex , or
in convex position if no point lies inside the convex hull of other points.
 Theorem 1.2 . 
 Let n ≥ 5 n\geq 5 . For any convex point set X ⊆ ℝ 2 X\subseteq\mathbb{R}^{2} with
 | X | = n |X|=n , it cannot happen that all distances except the diameter occur
more than n n times. 
 Given a point set X ⊆ ℝ 2 X\subseteq\mathbb{R}^{2} , let L 1 = L 1 ​ ( X ) L_{1}=L_{1}(X) be the set of vertices of
the convex hull of X X , called the first (outer) convex layer of
 X X . Similarly, the second convex layer L 2 = L 2 ​ ( X ) L_{2}=L_{2}(X) of X X is the set of
vertices of the convex hull of X ∖ L 1 X\setminus L_{1} . Note that X X is convex if and only if L 2 L_{2} is
empty. It follows from definition that X X is convex if and only if
 | L 1 | = | X | |L_{1}|=|X| . Next we confirm Conjecture  1.1 for “not too convex”
point sets, namely for point sets whose first and second convex layers are not
too large.
 Theorem 1.3 . 
 Let X ⊆ ℝ 2 X\subseteq\mathbb{R}^{2} be a set of n ≥ 2 n\geq 2 points. If 
 min ⁡ { 3 2 ​ ( | L 1 | + | L 2 | ) , 4 3 ​ | L 1 | + 2 ​ | L 2 | ,  2 ​ | L 1 | + | L 2 | } ≤ n , \min\left\{\frac{3}{2}(|L_{1}|+|L_{2}|),\,\frac{4}{3}|L_{1}|+2|L_{2}|,\,2|L_{1}|+|L_{2}|\right\}\leq n, 
 then the second largest distance in X X can occur at most n n times. 
 Theorem  1.3 
directly implies that, if the ratio Δ ⁡ ( X ) / δ ⁡ ( X ) \Delta(X)/\delta(X) of a set X ⊆ ℝ 2 X\subseteq\mathbb{R}^{2} 
is small enough, then the second largest distance in X X occurs at most n n times.
 Corollary 1.4 . 
 If X ⊆ ℝ 2 X\subseteq\mathbb{R}^{2} is a set of n ∈ ℕ n\in\mathbb{N} points with Δ ⁡ ( X ) ≤ n 3 ​ π ​ δ ​ ( X ) \Delta(X)\leq\frac{n}{3\pi}\delta(X) ,
then μ ⁡ ( X , Δ 2 ) ≤ n \mu(X,\Delta_{2})\leq n . 
 Proof. 
 Assume without loss of generality that δ ⁡ ( X ) = 1 \delta(X)=1 , namely,
 Δ ⁡ ( X ) ≤ n 3 ​ π \Delta(X)\leq\frac{n}{3\pi} . Then, | L 1 | |L_{1}| and | L 2 | |L_{2}| are upper bounded by
the perimeter of the convex polygons formed by L 1 L_{1} and L 2 L_{2} ,
respectively. Since the perimeter of a convex polygon is at most π \pi times its
diameter, see  [ 25 , p. 76] , we have | L 1 | + | L 2 | ≤ 2 ​ n / 3 |L_{1}|+|L_{2}|\leq 2n/3 and thus
 μ ⁡ ( X , Δ 2 ) ≤ n \mu(X,\Delta_{2})\leq n by Theorem  1.3 .
∎ 
 Note that the multiplicity of the second largest distance can be larger than n n 
in some planar point sets, see  [ 23 , 24 ] . Thus, to fully resolve
Conjecture  1.1 , one could perhaps consider multiplicities of different distances
simultaneously and show that one of them must be at most n n . For instance, one could consider
the smallest and the second largest distance; however, as we demonstrate below,
their multiplicities can both be large.
 Proposition 1.5 . 
 Let m , n ∈ ℕ m,n\in\mathbb{N} with m ≤ ⌊ n / 2 ⌋ m\leq\lfloor n/2\rfloor . There exists a planar point set
 X X with | X | = n |X|=n , such that μ ⁡ ( X , Δ 2 ) ≥ 3 ​ m \mu(X,\Delta_{2})\geq 3m and μ ⁡ ( X , δ ) ≥ 3 ​ n − 5 ​ m + o ⁡ ( m ) \mu(X,\delta)\geq 3n-5m+o(m) . 
 By letting m = ⌊ 3 ​ n / 8 ⌋ m=\lfloor 3n/8\rfloor , we obtain that min ⁡ { μ ⁡ ( X , Δ 2 ) , μ ⁡ ( X , δ ) } ≥ 9 ​ n / 8 + o ⁡ ( n ) \min\{\mu(X,\Delta_{2}),\mu(X,\delta)\}\geq 9n/8+o(n) .
This also motivates the following problem.

 Determine 
 lim sup n → ∞ sup X ⊆ ℝ 2 , | X | = n min ⁡ { μ ⁡ ( X , Δ 2 ) , μ ⁡ ( X , δ ) } n . \limsup_{n\rightarrow\infty}\sup_{X\subseteq\mathbb{R}^{2},\,|X|=n}\frac{\min\{\mu(X,\Delta_{2}),\mu(X,\delta)\}}{n}. 
 1.2. Point sets with many large distance multiplicities 
 Erdős and Pach  [ 10 ] , see also  [ 8 , Problem 11] , asked the following question:
Given a set X ⊆ ℝ 2 X\subseteq\mathbb{R}^{2} of n n points, can it happen that
there are c 1 ​ n c_{1}n distances with multiplicities at least c 2 ​ n c_{2}n , for
some constant c 1 , c 2 > 0 c_{1},c_{2}>0 ? Bhowmick  [ 2 ] recently answered
their question in the positive: There exist arbitrary large planar
point sets X X , | X | = n |X|=n , such that there are ⌊ n / 4 ⌋ \lfloor n/4\rfloor 
distances which occur at least n + 1 n+1 times. Bhowmick  [ 2 ] also
considered higher multiplicities, distances that occur at least n + m n+m 
times, m ≥ 1 m\geq 1 . He showed that there are sets with at least
 ⌊ n 2 ​ ( m + 1 ) ⌋ \lfloor\frac{n}{2(m+1)}\rfloor 
distances that occur at least n + m n+m times. Observe that for m m linear in n n , this
lower bound is only Ω ⁡ ( 1 ) \Omega(1) . Here we give a substantial
improvement by showing that there exist X ⊆ ℝ 2 X\subseteq\mathbb{R}^{2} of
 n n points, such that at least n c / log ⁡ log ​ n n^{c/\log\log{n}} distances have
superlinear multiplicity in n n . For comparison purposes, note that
 n c / log ⁡ log ​ n = Ω ⁡ ( ( log ⁡ n ) α ) n^{c/\log\log{n}}=\Omega((\log{n})^{\alpha}) , for any fixed α > 0 \alpha>0 .
 Theorem 1.7 . 
 There exists some constant c > 0 c>0 such that for sufficiently large n ∈ ℕ n\in\mathbb{N} ,
at least n c / log ⁡ log ​ n n^{c/\log\log{n}} distances occur at least n 1 + c / log ⁡ log ​ n n^{1+c/\log\log{n}} times
in the n × n \sqrt{n}\times\sqrt{n} grid. 
 As mentioned earlier, Bhowmick  [ 2 ] answered the question of Erdős and Pach  [ 10 ] 
with constants c 1 = 1 / 4 c_{1}=1/4 and c 2 = 1 c_{2}=1 . One may ask whether the constant c 1 = 1 / 4 c_{1}=1/4 resulting
from his construction is the best possible. We extend the above investigation for the range c 2 > 1 c_{2}>1 .
More precisely, we show that there exist n n -element planar point sets with m m distances
so that c 1 ​ m c_{1}m distances occur at least c 2 ​ n c_{2}n times, for suitable constants c 1 > 0 c_{1}>0 , c 2 > 1 c_{2}>1 .
Proposition  1.8 below gives three sample combinations; these combinations are not exhaustive.

 1.4. Related work 
 Recall that f ⁡ ( n ) f(n) denotes the largest possible value of a 1 ​ ( X ) a_{1}(X) among
all subsets X ⊆ ℝ 2 X\subseteq\mathbb{R}^{2} of n n points. Determining f ⁡ ( n ) f(n) , also known as
the unit distance problem, is notoriously difficult. The current best upper
bound is O ⁡ ( n 4 / 3 ) O(n^{4/3}) established by Spencer, Szemerédi, and Trotter  [ 19 ] .
A simple and elegant argument based on crossing numbers is due to Székely  [ 20 ] . From the other direction,
it is conjectured by Erdős that a n × n \sqrt{n}\times\sqrt{n} section of the integer lattice
gives the correct order magnitude, n 1 + c / log ⁡ log ​ n n^{1+c/\log\log{n}} , and so the current best
upper bound seems far off. See also a recent survey by Szemerédi  [ 21 ] for more on this topic.
 Let A ⁡ ( n ) A(n) be the maximum value of ∑ a k ​ ( X ) 2 \sum a_{k}(X)^{2} over all X ⊆ ℝ 2 X\subseteq\mathbb{R}^{2} 
with | X | = n |X|=n . Erdős  [ 7 ] asked whether A ⁡ ( n ) = O ⁡ ( n 3 ​ ( log ⁡ n ) α ) A(n)=O(n^{3}(\log{n})^{\alpha}) 
holds for some positive constant α > 0 \alpha>0 . This question received a complete
answer via the work of Guth and Katz  [ 15 ] on the problem of distinct
distances. Specifically, the authors proved that the inequality holds with
 α = 1 \alpha=1 , i.e., A ⁡ ( n ) = O ⁡ ( n 3 ​ log ⁡ n ) A(n)=O(n^{3}\log{n}) , and is tight in the n × n \sqrt{n}\times\sqrt{n} integer grid.
Lefmann and Thiele  [ 17 ] proved that the sharper inequality A ⁡ ( n ) = O ⁡ ( n 3 ) A(n)=O(n^{3}) holds for convex point sets;
this bound is tight, e.g., for a regular n n -gon.

In Section  3 we will prove Theorem  1.7 and Proposition  1.8 .
Section  4 is devoted to proving Theorem  1.9 .
Finally, in Section  5 we give a simple answer to Question ( 4 ).

 Given a finite point set X ⊆ ℝ 2 X\subseteq\mathbb{R}^{2} , recall that δ ⁡ ( X ) < Δ 2 ​ ( X ) < Δ ⁡ ( X ) \delta(X)<\Delta_{2}(X)<\Delta(X)

 2.1. The convex case 
 Proof of Theorem  1.2 . 
 Let X ⊆ ℝ 2 X\subseteq\mathbb{R}^{2} be an arbitrary convex set of n n points. Let

minus one vertex.
A classical result of Altman  [ 1 ] states that

Moreover, Altman proved that if n n is odd and X X determines exactly ⌊ n / 2 ⌋ \lfloor n/2\rfloor distances,
then X = R n X=R_{n} ; in particular, a ⁡ ( X ) = ( n , n , … , n ) a(X)=(n,n,\ldots,n) . See also  [ 9 , 13 ] . 
 The complementary result for even n n is due to Fishburn  [ 12 ] .
Suppose that n ≥ 6 n\geq 6 is even and X X  determines exactly ⌊ n / 2 ⌋ \lfloor n/2\rfloor distances. Then 
 (i) 
 for n = 6 n=6 , there exist exactly two possibilities, a ⁡ ( X ) = ( 6 , 6 , 3 ) a(X)=(6,6,3) , or a ⁡ ( X ) = ( 5 , 5 , 5 ) a(X)=(5,5,5) ;

 In particular, for the second case we have a ⁡ ( X ) = ( n , n , … , n , n / 2 ) a(X)=(n,n,\ldots,n,n/2) or a ⁡ ( X ) = ( n − 1 , n − 1 , … , n − 1 ) a(X)=(n-1,n-1,\ldots,n-1) . 
 We can now finalize the proof. If X X determines strictly more than ⌊ n / 2 ⌋ \lfloor n/2\rfloor 
distinct distances and all distances smaller than Δ \Delta occur more than n n times,
then the number of point pairs is at least

 a contradiction. Otherwise, X X determines exactly ⌊ n / 2 ⌋ \lfloor n/2\rfloor distinct distances,
and it is easy to check that all possible cases listed previously satisfy the requirements.
∎
